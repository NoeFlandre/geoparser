# Archived experiment inventories

These files preserve source pins, data manifests, and written reviews for five
offline experiment packages removed from the active scripts and documentation.
They are historical records, not supported commands or runnable benchmark
entrypoints. No model weights or corpus text were copied here.

The archive index records the former path and SHA-256 of each preserved data
manifest and source pin. The archived reviews and plans retain their text as
historical documentation. The existing MasakhaNER inventory report and UNER
source audit remain in their original `benchmark-evidence/` locations. The
UNER audit's `source_snapshot` field keeps its original value,
`scripts/uner_benchmark/sources.json`, to preserve what it recorded at the time.
That file is now at `benchmark-evidence/archives/uner/sources.json`; the archive
index maps the original and archive paths and records the unchanged SHA-256.
The audit itself is unchanged. The historical PAN-X report and 2026-09-23
benchmark evidence also remain unchanged.

No benchmark evaluation was completed for these archived experiments. Their
source-review documents describe what was checked and list unresolved limits.
